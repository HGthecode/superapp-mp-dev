# 移动端设计系统

单技能、两阶段：**阶段一用灵感库定方向，阶段二按档位体系出稿**。不绑定具体产品、品牌色或组件库实现。

## 核心原则

1. **体系优先于数值**：规范定义结构（色阶层级、字号阶梯、档位划分）；品牌色组为可配置参数，结构不可破坏。
2. **取值唯一来源**：出稿时所有取值（色值、字号、圆角、阴影、间距）只认 [system.md](system.md) 档位。`inspiration/` 灵感库只提供方向（风格气质、配色意向），其中的示例值（如圆角 12–16px、间距 xs–xl、具体十六进制色）**禁止直接进入设计稿**。
3. **375px 画板**：以 375px 宽、高至少 814px 的画板为基准（1px = 2rpx），必须模拟顶部状态栏。
4. **先基线后批量**：先制作并导出 1 个代表性画板作为视觉基线，确认后再按 2–3 个一批扩展。
5. **不绑定组件**：只定义「看起来应该是什么」，不规定组件库实现。

## 工作流

### 阶段一：定方向（风格与品牌色意向）

1. **风格气质**：按产品类型从 [inspiration/](inspiration/README.md) 检索——风格百科（`design-styles.md`）、`ui-ux-data/styles.csv`（67 种风格，含适用/禁用场景）、`design-psychology.md`（色彩情绪与版式心理）。
2. **品牌主色意向**：`ui-ux-data/colors.csv` 按产品类型给出主色/CTA 意向，结合 `design-psychology.md` 情绪联想收敛为 1 个主色方向，与用户确认。
3. 风格只影响气质与品牌色相；**字体族固定 Noto Sans SC**，档位结构不随风格漂移。

### 阶段二：按档位出稿（Penpot）

1. 读取 [system.md](system.md)：从确认的主色按配置规则派生品牌色组（6 令牌），其余取值全部从档位选取。
2. 执行 [penpot-workflow.md](penpot-workflow.md) 的硬性约束（画板、令牌、文本行高、图标、防错规则）。
3. **设计后验收**：按 penpot-workflow.md 的视觉验收门禁逐项核对（结构检查、投影/描边/留白/图标审计、逐页 PNG 视觉检查），任一画板未通过禁止交付。

## 硬值速查（详见 system.md）

- 画板 375 × ≥814px，页面左右边距 16px，间距按 8px 网格
- 卡片：白底 + 圆角 20 + 纯黑 `#000000` 投影 `0/3/12px` @3%
- 输入框：高 58 + 圆角 14 + `#F5F7FB`（白容器内常态无描边）
- 主按钮：高 56 + 圆角 16 + 品牌主色底白字 + 主色投影 `0/6/16px` @32%
- 图标统一 remix-icon，图层名 `icon / <remix-icon-name>`；字体 Noto Sans SC，正文行高 1.4
