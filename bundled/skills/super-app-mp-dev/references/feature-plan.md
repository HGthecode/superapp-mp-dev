# 新功能开发计划（须用户确认）

**做任何新功能开发时**（含：新增页面/流程、改控制台、加云函数、改云数据、扩大已有模块），**禁止直接改代码 / 改 schema / `sa-mp data push` / `sa-mp fn push`**。

必须先输出开发计划 → **等用户明确确认（或按反馈改完后再确认）** → 严格按**最终确认方案**执行。

仅改文案、修明确 bug、调样式且不新增功能点时，可跳过本流程。

缺任一章视为计划不完整，不得开干。某章本次无变更时写「无」并一句说明原因，不可省略标题。
